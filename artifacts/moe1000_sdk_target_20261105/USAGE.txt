MoE1000：SDK 目标关节角度硬约束版本

主推理模型：exported/policy.onnx
输入 obs: float32 [1,225]；输出 actions: float32 [1,12]。
关节顺序 FL、FR、RL、RR，每腿 hip、thigh、calf。
使用 params/deploy.yaml 中原有观测缩放、五帧分组历史、动作缩放 0.25、默认角度、20/0.5 PD 和 20 ms 控制周期。
将模型返回的有界动作写入 last_action 历史。导出模型已内置逐关节动作边界；这些边界保证原仿射解码得到的目标角度位于 SDK 坐标系限位内。
exported/contract.json 保存精确边界、顺序和解码约定。

model_1000.pt 包含训练用原始 actor、critic、Adam 状态和更新计数。部署请使用上述带限幅的 ONNX；仅导出检查点内部原始 actor 会丢失目标角度硬约束。
command_export/command_policy.onnx 是另一种三输出接口，直接提供策略顺序目标角度、已执行动作历史、SDK 顺序目标角度。其 SDK 目标角度无需再次乘动作缩放或添加默认角度，详见该目录 contract.json。

训练保持原 MoE1000 的预训练起点、128 环境、32 workers、两级 15 cm 台阶、PPO 参数、奖励权重与原生 MuJoCo 动力学。新增发送目标投影和对应执行动作历史，未新增惩罚权重；完成 1000 次更新。
髋角使用原应用 ±48 度限位；大腿前后腿分别按官方 URDF/SDK 坐标范围；小腿范围 [-2.7227,-0.83776] rad。精确 float32 边界以 JSON 为准。

最终 ONNX 独立评估：129 回合中 123 次成功、3 次超时、2 次碰墙、1 次机身接触；484548 个关节目标值零超限。
硬约束作用于发送的目标角度。实际角度、速度、跟踪误差仍有违规，全部关节保护未通过；已有控制器保护应保留。平台停车继续使用仿真几何触发的外部零速度命令。
